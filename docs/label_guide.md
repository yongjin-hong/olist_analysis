## 2. 카테고리 (7개)

| 라벨 | 정의 | 포함 예시 |
|---|---|---|
| 배송 지연 | 상품이 늦게 오거나 아직 안 옴 | 예정일 초과, 미수령, 분실, 배송완료로 뜨는데 못 받음, 다른 주소·도시로 배송됨, 교환·재발송 지연 |
| 제품 오배송 | 주문과 다른 상품, 또는 객관적 사양이 다른 상품이 옴 | 다른 모델·브랜드, 색·크기·용량·소재·전압·무늬가 표기와 다름 |
| 제품 불량 | 받은 상품에 **객관적 결함**이 있음 | 작동 안 함, 파손·찌그러짐, 흠집·중고 같음, 마감·조립 불량, 거칠고 얇음 등 구체적 상태 묘사 |
| 누락 | 주문 수량이나 구성품 일부가 안 옴 | "2개 샀는데 1개 옴", 부품·필터·상자 빠짐 |
| 위조·비정품 | 정품(브랜드 상품)으로 판매했는데 가품·호환품·무브랜드가 옴 | 레플리카, 무브랜드 카트리지, 정품 대신 호환품, 애플 케이블 대신 무브랜드 케이블 |
| 제품 불만족 | 결함은 없지만 제품에 대한 **주관적 아쉬움** | "소재가 아쉬움", "배터리가 금방 닳음", "냄새가 강함", "생각과 많이 다름", "기대한 품질이 아님", "자주 버벅임"(성능 불만), "상자 없이 허술하게 옴" |
| 기타 | 위에 해당하지 않거나 원인을 알 수 없음 | 아래 목록 참고 |

**기타에 포함되는 것**
- 욕설·한 단어·"별로예요"·"의견 없음" 등 **제품을 언급하지 않는** 원인 불명 불만
- 고객의 주문 실수로 보이는 **호환 문제** (차종·기기에 안 맞음)
- 결제·취소 문제 (취소했는데 배송됨, 결제 금액 오류 등), 재고 문제, 응대 불만
- 가격·배송비가 비싸다는 불만
- 우체국 직접 수령, 포장만 손상(제품은 정상) 등 단순 배송 불만
- 점수와 반대되는 칭찬

## 3. 경계 규칙

### 3-1. 제품 오배송 vs 제품 불량 vs 제품 불만족
- 색·크기·용량·모델·소재처럼 **객관적 사양이 다르면** → 제품 오배송
- 작동 안 함·파손·흠집처럼 **객관적 결함이 드러나면** → 제품 불량
- 결함 묘사 없이 제품에 대한 **주관적 아쉬움만 있으면** → 제품 불만족
- 제품을 특정하지 않은 막연한 불만("별로예요") → 기타

### 3-2. "다른 상품이 왔다"는 표현
- 실제로 다른 상품이 왔으면 → 제품 오배송
- 품질이 나빠서 "다른 물건 같다"는 **비유**라면 → 품질 불만으로 보고 3-1 적용

### 3-3. 원인이 둘 이상일 때 (우선순위)

```
객관적 제품 문제 (제품 오배송 / 제품 불량 / 누락 / 위조·비정품)
  > 제품 불만족
    > 배송 지연
      > 기타
```

- 객관적 제품 문제끼리는 → **더 구체적으로 서술된 원인**
- 구체성이 비슷하면 → **먼저 언급된 원인**

### 3-4. 예외: 교환·재발송 지연 → 배송 지연
- 이미 받은 제품의 문제(불량·누락 등)에 대해 **교환·재발송 처리가 늦어지는 것이 불만의 핵심**이면 → 배송 지연
- 이 규칙은 3-3보다 **우선**한다.
- 지금 받은 물건의 상태가 아니라 **처리 속도**를 문제 삼는지 본다.
- 주관적 불만(마음에 안 듦)으로 인한 **환불·반품 처리 지연**은 해당하지 않는다 → 원래 불만 기준 (예: 제품 불만족)

### 3-5. 호환 문제·고객 실수
- 제품은 정상인데 고객의 차종·기기에 안 맞는 경우 → 기타 (고객 주문 실수로 판단)
- 고객의 **사용 실수**로 고장 난 경우 → 기타 (예: 110V 기기를 220V 콘센트에 연결)
- **판매자가 호환을 표기했는데** 안 맞으면 → 제품 오배송 (사양 표기 불일치)
  - 예: "지정 기기용 필름인데 화면보다 작음", "모든 수신기에 된다던 리모컨이 안 됨"
- 판매자가 주문과 **다른 모델을 보냈다는 서술**이 명확하면 → 제품 오배송
- 누구 실수인지 불명확하면 → 기타

### 3-6. 구성품 범위
- 제품에 붙어 있어야 할 부품(핀·나사 등)이나 구성품이 빠졌으면 → 누락
- 상자: **설명에 포함된다고 돼 있었는데** 빠졌으면 → 누락
- 상자: 그런 서술 없이 "상자 없이 허술하게 왔다"는 **포장·구성 불만**이면 → 제품 불만족

### 3-7. 제목과 본문이 모순될 때
- **본문**을 기준으로 판단한다. (예: 제목 "아주 좋음" + 본문 "부품이 빠졌다" → 누락)

### 3-8. 일부만 받았을 때: 누락 vs 배송 지연
- 나머지가 오고 있다는 **근거**가 서술되면 → 배송 지연 (분할 배송)
  - 근거: 배송 중·우체국에 있음, 늦게 도착함, 함께 오기로 한 **예정일이 지났음**, **판매자·상담원이 따로 발송했다고 안내함**
- 그 외 "일부만 왔다"면 → 누락 (배송완료로 표시돼 있어도 동일)
- "아직·지금까지 1개만 왔다"처럼 **기다린다는 표현만으로는** 배송 지연으로 보지 않는다 → 누락
- "배송 중이길 바란다"처럼 **고객의 추측·희망**도 근거가 아니다 → 누락
- 같이 산 다른 상품은 받고 **일부 상품만 통째로 못 받았어도** → 누락

### 3-9. 포장만 손상
- 포장이 찌그러지거나 찢어졌지만 **제품은 정상**이면 → 기타
- 포장 손상과 함께 **제품도 파손**됐으면 → 제품 불량

### 3-10. 과장 광고·짝퉁 은어
- "과장 광고"라는 표현만 있고 **구체적 사양 차이가 없으면** → 제품 불만족
- 야광·전압·크기처럼 **구체적 사양이 표기와 다르면** → 제품 오배송
- "파라과이산"처럼 싸구려 짝퉁을 뜻하는 은어만 있고 **정품으로 팔았다는 서술이 없으면** → 제품 불만족
- **"사진·광고와 다르다"**, "사진은 이건데 받아 보니 딴 거"처럼 **무엇이 다른지 없이** 다르다는 인상만 있으면 → 제품 불만족
  - 색·크기·모델 등 **무엇이 다른지 서술**되거나 "주문한 것과 다른 상품이 왔다(잘못 왔다)"고 하면 → 제품 오배송
  - 다르다는 인상 + 작동 안 함처럼 **객관적 결함**이 함께 있으면 → 제품 불량 (3-3)

### 3-11. 상품 설명 부족·불명확
- 상품은 주문대로 왔는데 **설명이 부족하거나 불명확**해서 기대와 달랐다는 불만 → 제품 불만족
  - 예: "전구 포함인지 정보가 없었다", "크기가 설명에 없어서 클 줄 알았다", "무선인 줄 알았는데 유선, 주문대로는 옴"
- 설명에 **명시된 사양과 다르면** → 제품 오배송 (3-1)

### 3-12. 유통기한 임박
- 제조일이 오래됐거나 유통기한이 얼마 안 남았다는 불만 → 제품 불만족 (제품 자체에 결함이 있는 것은 아님)
- 유통기한이 **이미 지났거나** 변질됐다는 서술이 있으면 → 제품 불량

### 3-13. 짧은 배송 표현
- "아직 기다리는 중", "배송 문제", "내 상품 어디 있나요?"처럼 **배송을 기다리거나 배송 문제를 짧게 언급**한 것 → 배송 지연
- 무엇을 기다리는지 알 수 없는 "답변 기다려요", "평가 보류" 등 → 기타
